The solution

One agent. One job.

The agent's reasoning loop Observe→ Reason→ Act→ Observe result→ Repeat

Agent flow

From one transaction to one explainable decision

Every evaluation is bounded, auditable, and traceable end-to-end with a single request ID.

Student Base44 app RealRelay agent Data store
  1. Student adds a transaction in SmartBudget AI
  2. Base44 saves the transaction and emits transaction.created
  3. Base44 calls POST /agent/evaluate with the full financial context
  4. Deterministic engine computes spend, velocity, projection & risk score
  5. Reasoning layer selects one intervention and explains it
  6. Agent returns a structured, schema-validated JSON decision
  7. Base44 stores the decision and the audit record
  8. Student sees the proactive alert in-app — accept, dismiss, or ask "why?"
  9. Student's response flows back to /agent/feedback
  10. Agent adapts tone, timing & amounts — never permissions

Deterministic guardrails around every AI recommendation

✅ All money math computed by code, never the LLM ✅ Duplicate alerts suppressed by cooldown + dedup key ✅ No transfers without explicit approval ✅ Consent changes apply instantly ✅ Full audit trail per evaluation
